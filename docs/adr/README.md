# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) in MADR style.

## Format

Each ADR is a Markdown file named `NNNN-short-title.md`, numbered sequentially starting at `0001`.

Each ADR has three sections:

- **Context.** The situation and forces that make a decision necessary. States facts, not opinions.
- **Decision.** The choice made, stated as a single clear sentence.
- **Consequences.** The results of the decision, positive and negative, including trade-offs accepted.

## When to write one

Write an ADR when a decision is hard to reverse, affects the architecture, or a future reader would otherwise have to reconstruct the reasoning from git history.
